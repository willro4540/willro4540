### 시작점: [`repo-index`](https://github.com/willro4540/repo-index)

이 계정의 모든 저장소(개발 프로젝트 + 기술 리서치)를 다루려면 먼저
**[`repo-index/Claude.md`](https://github.com/willro4540/repo-index/blob/main/Claude.md)**
를 읽는다 — AI 운영 지침 루트이며, 저장소 전체 목차는
[`repo-index/README.md`](https://github.com/willro4540/repo-index/blob/main/README.md)에 있다.

사람이든 AI든, "깃허브 참고해"라는 지시를 받으면 이 두 파일부터 확인할 것.
